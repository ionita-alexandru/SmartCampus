# SmartCampus

Projet Web dynamique 2026 – ECE ING2

SmartCampus est une plateforme web dynamique de gestion académique destinée aux universités et écoles d’ingénieurs.

## Fonctionnalités

- Gestion des étudiants
- Gestion des enseignants
- Gestion des cours
- Gestion des inscriptions
- Gestion des notes
- Emploi du temps
- Gestion des rôles utilisateurs

## Technologies

- HTML
- CSS
- JavaScript
- PHP
- MySQL
